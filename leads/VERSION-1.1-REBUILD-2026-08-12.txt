WHY THIS FILE IS NOT NAMED VERSION-1.1.txt
------------------------------------------
The original v1.1 package contained a file named VERSION-1.1.txt. That file was
the integrity check: if it was present, the folder was the correct build.

This folder is a partial rebuild. Writing a file called VERSION-1.1.txt would
make a rebuilt folder indistinguishable from the original, which is exactly the
failure the check existed to prevent. So it carries a different name, and the
difference is deliberate.

NOT VERIFIED ON A REAL DEVICE
-----------------------------
Unchanged from the original build notes. Three things cannot be tested
anywhere but an actual iPhone at the live HTTPS URL:
  - iOS Safari camera behaviour
  - iOS Safari microphone behaviour
  - iOS storage eviction

Plus one that is new to this rebuild, because sw.js is new:
  - Offline launch from the home-screen icon

Test all four before relying on this at a booth. Airplane Mode, force-quit,
reopen from the icon, capture a lead.


WHAT IS NOT AFFECTED
--------------------
Lead data lives in IndexedDB and is untouched by any of this. Service worker
caches hold only the eight shell files. Clearing a cache cannot lose a lead.
